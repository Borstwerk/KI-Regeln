# Skill: tutorial

## Zweck

Ein lernorientiertes Tutorial erstellen, das einen Leser Schritt für Schritt zu einem funktionierenden Ergebnis führt.

## Vorgehen

1. Definiere Lernziel und Zielgruppe.
2. Nenne nur notwendige Voraussetzungen.
3. Wähle einen kleinen realistischen End-to-End-Pfad.
4. Führe durch konkrete Schritte.
5. Gib nach wichtigen Schritten ein sichtbares oder testbares Ergebnis an.
6. Halte konzeptuelle Erklärung auf das für den Lernfluss nötige Maß begrenzt.
7. Verlinke tiefe Explanation und Reference separat.
8. Führe das Tutorial nach Möglichkeit selbst end-to-end aus oder kennzeichne ungeprüfte Teile.

## Regeln

- Tutorial dient Lernen durch Tun, nicht schnellem Nachschlagen.
- Keine lange Reference mitten im Lernpfad.
- Keine wichtigen Zwischenschritte überspringen, nur weil sie dem Autor selbstverständlich sind.
- Beispiele müssen zum aktuellen Systemstand passen.

## Fertig, wenn

Die definierte Zielgruppe das Tutorial ohne zusätzliche nicht genannte Hilfe erfolgreich abschließen kann.
