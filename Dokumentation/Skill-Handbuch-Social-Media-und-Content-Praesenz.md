# Skill-Handbuch – Social Media und Content-Präsenz

Dieses Handbuch hilft bei der Auswahl der neun Skills aus `Social-Media-und-Content-Praesenz/`.

## Schnellauswahl

| Wenn die Aufgabe lautet … | Primärer Skill |
|---|---|
| bestehende Profile, Posts und Evidence als Iststand erfassen | `content-presence-baseline` |
| klären, was und warum veröffentlicht werden soll | `social-content-strategy` |
| Backlog, Kadenz und Content-Kalender planen | `editorial-planning` |
| einen konkreten Social-Draft entwerfen | `social-content-design` |
| eine Aussage für andere Plattformen adaptieren | `platform-content-adaptation` |
| ein Source-Asset in mehrere Content-Derivatives überführen | `content-repurposing` |
| Replies, Community-Dialog oder Moderationsvorschläge entwerfen | `community-engagement` |
| reale Social-Analytics auswerten | `content-performance-analysis` |
| eine breite Presence-/Readiness-Prüfung durchführen | `content-presence-review` |

## Auswahlregeln

### `content-presence-baseline`

Wenn zuerst geklärt werden muss: **Was tun wir heute wirklich und welche Evidence haben wir?** Read-only.

### `social-content-strategy`

Wenn Ziele, Audience, Positionierung, Themen und Plattformrollen zusammengesetzt werden sollen. Keine Pflichtzahl für Pillars, Frequenz oder Formate.

### `editorial-planning`

Wenn Strategie in Backlog, Serien, Slots, Owner und Produktionsstatus übersetzt wird. Kalender ≠ Scheduling.

### `social-content-design`

Für einen konkreten Post-, Thread-, Carousel- oder Community-Draft. Allgemeine natürliche Sprache bleibt zusätzlich beim Schreibskill.

### `platform-content-adaptation`

Wenn dieselbe belegte Botschaft auf mehreren Plattformen anders strukturiert werden soll. Aktuelle Limits/Features bei Materialität verifizieren.

### `content-repurposing`

Wenn aus einem Source-Asset mehrere eigenständige Inhalte entstehen sollen. Source-Wahrheit und Rechte bleiben erhalten.

### `community-engagement`

Für Reply-Drafts, Dialogpriorität und Moderations-/Eskalationsvorschläge. Keine automatische Außenaktion.

### `content-performance-analysis`

Für reale Plattformmetriken und Lernhypothesen. Metrikdefinition, Zeitraum und Nenner gehören zur Evidence.

### `content-presence-review`

Für den unabhängigen breiten Audit. Findings statt Auto-Fixes; `READY_FOR_LOCAL_GATE` ist keine Publishing-Freigabe.

## Wichtige Near-Misses

| Aufgabe | Stattdessen |
|---|---|
| externe Fakten/Trends verifizieren | Recherche-Skills |
| reines Stilreview | `natuerliches-schreiben` / `stilreview` |
| Bild erzeugen oder retuschieren | Bildarbeit |
| Website/Landingpage | Webentwicklung |
| konkrete Produkt-/Kampagnenziele definieren | Requirements / lokale Business-Policy |
| Paid-Media-Bidding/Targeting | lokaler Ads-/Marketing-Prozess |
| reale Veröffentlichung | lokales External-Action-/Publishing-Gate |

## Keine zentralen Pflichtwerte

Nicht zentral festgeschrieben werden:

- Posts pro Woche;
- beste Uhrzeit;
- Anzahl Hashtags;
- Pillar-Prozente;
- Plattform-Rankinggewichte;
- Hook-Formeln;
- Engagement-Rate-Benchmarks;
- Reichweitenziele.

## Empfohlene Skill-Ketten

### Neue Präsenz

```text
lokale Goals / Audience
→ social-content-strategy
→ editorial-planning
→ social-content-design
→ content-presence-review
→ lokales Publishing-Gate
```

### Bestehende Präsenz

```text
content-presence-baseline
→ content-performance-analysis
→ social-content-strategy
→ editorial-planning
```

### Source-Asset verteilen

```text
content-repurposing
→ platform-content-adaptation
→ social-content-design
→ editorial-planning
```

### Unabhängiger Audit

```text
content-presence-baseline
+ content-performance-analysis soweit Evidence vorhanden
→ content-presence-review
→ lokales Gate
```

## Leitgedanke

> Nicht für den Algorithmus posten, sondern für ein reales Ziel und reale Menschen – und mit echter Evidence lernen, was funktioniert.
