# Downstream-Export-Kontrakt

Verbindlich fuer die Spaltenreihenfolge des CSV-Exports ist das Dokument
`EXPORT-CONTRACT-v3` des abnehmenden Systems.

**Dieses Dokument liegt dem Review-Paket absichtlich nicht bei.**
Ob eine Aenderung der Spaltenreihenfolge zulaessig ist, kann ohne den Kontrakt
nicht entschieden werden.
