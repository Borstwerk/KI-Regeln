# Repository-Standards (Auszug)

- KISS: keine Abstraktion ohne aktuellen Bedarf. Ein zweites Format ist kein Bedarf
  fuer eine Registry.
- Neue externe Abhaengigkeiten erfordern eine dokumentierte, freigegebene Entscheidung.
  Ohne diese Entscheidung ist die Aufnahme ein Freigabehindernis.
- Aenderungen ausserhalb des beauftragten Slices sind bewusst zu entscheiden,
  nicht unbemerkt mitzuliefern.
