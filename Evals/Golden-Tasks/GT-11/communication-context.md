# Kommunikationskontext

- Empfänger: direkte Führungskraft.
- Aktuelle Aufgabe A hat bestätigte Deadline Freitag.
- Neu hinzugekommene Aufgabe B benötigt denselben verfügbaren Arbeitsblock.
- Mit der vorhandenen Kapazität kann bis Freitag nur A oder B zuverlässig abgeschlossen werden.
- Es gibt keine bestätigte Priorisierung.
- Ziel der Nachricht: Führungskraft soll entscheiden, welche Aufgabe Vorrang hat.
- Kein Konflikt und keine persönliche Beschwerde.
- Keine besondere Voice- oder Stilvorgabe.
