# Workflow: Content-Präsenz Baseline und Strategie

## Ziel

Eine bestehende oder neue Social-/Content-Präsenz aus lokalen Zielen, Audience und Evidence belastbar ausrichten.

## Ablauf

```text
1. lokale Requirements / Brand / Audience
→ 2. content-presence-baseline bei bestehender Präsenz
→ 3. Research-/Evidence-Lücken klären
→ 4. social-content-strategy
→ 5. Plattformrollen / Themen / Formate
→ 6. Erfolgssignale / Lernfragen
→ 7. content-presence-review
→ 8. lokales Strategie-/Brand-Gate
```

Keine Profiländerung oder Veröffentlichung wird durch diesen Workflow autorisiert.
