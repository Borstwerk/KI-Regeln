# Workflow: Content Performance und Readiness Review

## Ziel

Eine laufende Content-Präsenz mit realer Performance- und Community-Evidence prüfen und begrenzte nächste Entscheidungen ableiten.

## Ablauf

```text
1. lokale Ziele / KPI-Definitionen
+ aktuelle Content-Historie
+ native Analytics / verifizierte Exports
+ Community-Signale
→ 2. content-performance-analysis
→ 3. content-presence-baseline bei größerem Driftbedarf
→ 4. content-presence-review
→ 5. Findings / Missing Evidence / Lernhypothesen
→ 6. Strategie-/Editorial-Anpassung als separater lokaler Entscheid
→ 7. kein automatisches Publishing
```
