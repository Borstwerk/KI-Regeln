# Workflow: Cross-Platform-Adaption und Repurposing

## Ziel

Eine belastbare Kernidee oder ein Source-Asset mehrfach nutzen, ohne Copy-Paste, Claim-Drift oder Low-Value-Reupload.

## Ablauf

```text
1. Source Asset / bestätigte Kernbotschaft
→ 2. content-repurposing bei mehreren Derivatives
→ 3. platform-content-adaptation je Zielplattform
→ 4. social-content-design für finale Drafts
→ 5. Source / Claims / Rechte / Disclosure prüfen
→ 6. editorial-planning für Verteilung
→ 7. lokales Publishing-Gate
```

Repurposing erzeugt neue Darstellungen, keine neue Wahrheit.
