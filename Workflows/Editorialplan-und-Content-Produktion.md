# Workflow: Editorialplan und Content-Produktion

## Ziel

Aus bestätigter Content-Strategie einen realistischen Produktionsfluss bis zum publish-bereiten Draft erzeugen.

## Ablauf

```text
1. social-content-strategy / bestätigte Themen
→ 2. editorial-planning
→ 3. Research / Source Verification bei Bedarf
→ 4. social-content-design
→ 5. natuerliches-schreiben / Stilcheck bei Bedarf
→ 6. Bild-/Visual-Brief an Bildarbeit bei Bedarf
→ 7. Claim / Disclosure / Rights Review
→ 8. READY_FOR_LOCAL_PUBLISH_GATE
→ 9. Publishing außerhalb dieses Workflows
```
