# Skill: Frontend Design

## Zweck

Entwickle für eine Website oder Weboberfläche eine konkrete, begründete Designrichtung, bevor Komponenten im Detail gebaut werden.

## Verwenden wenn

- eine neue Seite oder Oberfläche gestaltet wird;
- vorhandenes UI sichtbar generisch oder templatisiert wirkt;
- Produkt, Publikum und Wirkung in eine eigenständige visuelle Sprache übersetzt werden sollen.

## Nicht verwenden als

- Ersatz für lokale Markenregeln;
- automatischen Komplett-Redesign-Auftrag;
- Accessibility- oder Performance-Review.

## Vor Beginn klären

1. Produkt / Seitentyp;
2. Zielgruppe;
3. Hauptaufgabe der Seite;
4. vorhandene Marke oder Designregeln;
5. reale Inhalte oder Contentstruktur;
6. technische und responsive Grenzen.

## Arbeitsweise

1. Formuliere die wichtigste Aussage oder Aufgabe der Seite.
2. Leite daraus eine konkrete Designrichtung ab.
3. Definiere ein bis zwei prägende Signature Elements.
4. Bestimme Typografie-, Farb-, Surface- und Rhythmuscharakter auf hoher Ebene.
5. Benenne explizit unpassende oder generische Defaultmuster.
6. Prüfe, ob Hero und Hauptabschnitte aus dem Inhalt statt aus einem Standardtemplate entstehen.
7. Übergib die Richtung als klaren Designbrief oder lokale `DESIGN.md`-Grundlage.

## Anti-Slop-Check

Nicht reflexartig verwenden:

- generischen SaaS-Hero;
- lila/blauen Gradient;
- Card-Raster für jeden Abschnitt;
- Icon-Kacheln ohne Informationsfunktion;
- Glow/Blur/Glass als Modernitätsersatz;
- Fake-KPIs oder Testimonials;
- Scroll-Reveal auf jedem Abschnitt.

Diese Mittel sind erlaubt, wenn sie konkret begründet sind.

## Ausgabe

Mindestens:

```text
Produkt / Zielgruppe
Seitenthese / Hauptaufgabe
Designrichtung
Signature Elements
Typografischer Charakter
Farb-/Surface-Logik
Rhythmus / Dichte
Interaktionscharakter
Bewusste Ausschlüsse / Anti-Patterns
Offene lokale Entscheidungen
```

## Stop-Regeln

Stoppe und kläre, wenn:

- Produktziel oder Zielgruppe grundlegend unklar ist;
- eine neue Markenentscheidung nötig wäre;
- vorhandene lokale Designregeln widersprüchlich sind;
- eine technische Grenze die gewählte Richtung wesentlich verändert.

## Leitgedanke

> Gestalte für dieses Produkt, nicht für die statistische Durchschnittswebsite im Trainingsmaterial.
