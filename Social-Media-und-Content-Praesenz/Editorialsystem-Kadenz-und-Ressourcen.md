# Editorialsystem, Kadenz und Ressourcen

## Zweck

Ein Editorialsystem übersetzt Strategie in eine realistisch produzierbare Abfolge von Inhalten.

## Planungsebenen

```text
Ziel / Kampagne / laufende Präsenz
→ Themen / Pillars
→ Content-Backlog
→ konkrete Slots / Serien / Formate
→ Produktionsstatus
→ Review / Freigabe
→ lokales Scheduling / Publishing
```

## Kadenz

Kadenz ist eine Ressourcen- und Lernentscheidung, kein universeller Algorithmuswert.

Berücksichtigen:

- Produktionskapazität;
- Qualität und Evidence-Bedarf;
- Community-Fähigkeit nach Veröffentlichung;
- Wiederverwendung vorhandener Assets;
- Kampagnen-/Eventtermine;
- Lernbedarf und Messfenster;
- Plattform- oder Audience-Eigenheiten, soweit belegt.

## Content-Backlog

Ein guter Backlog enthält mindestens:

- Thema / Kernidee;
- Ziel / Audience;
- Quelle oder Evidence-Basis;
- geplantes Format / Plattformrolle;
- Status;
- Owner;
- relevante Deadline;
- Disclosure-/Risk-Hinweise, falls nötig.

## Anti-Dogmen

- keine Pflicht „täglich posten“;
- keine universelle Wochenquote;
- keine Kalenderfüllung mit schwachen Ideen nur für Konsistenz;
- keine automatische Veröffentlichung aus einem Plan.
