# Projekt – Agent Instructions

Diese Datei ist eine Vorlage für repo-lokale Agent-Anweisungen.

Sie verweist auf allgemeine Arbeitsweisen, enthält aber nur die projektspezifischen Ergänzungen, die ein Agent innerhalb dieses Repositories wirklich benötigt.

## Vor relevanter Änderung

1. Konkreten Auftrag beziehungsweise Requirement identifizieren.
2. Relevante Projekt-, Architektur-, Entscheidungs- und Testdokumentation lesen.
3. Bestehenden Code und vorhandene Tests prüfen.
4. Den für das Projekt gültigen Entwicklungsprozess respektieren.
5. Passende allgemeine Skills nur innerhalb ihres vorgesehenen Kontexts verwenden.

## Projektspezifische Leitplanken

Hier nur Regeln aufnehmen, die tatsächlich für dieses Projekt gelten.

Beispiele:

- fachliche Scope-Grenzen;
- besondere Daten- oder Sicherheitsregeln;
- erlaubte oder verbotene externe Abhängigkeiten;
- Release- oder Plattformanforderungen;
- notwendige manuelle Abnahmen.

Keine allgemeinen Regeln duplizieren, wenn ein Verweis genügt.

## Freigabe

Grüne Tests allein sind kein vollständiger Freigabenachweis.

Notwendige manuelle Prüfungen, externe Validatoren oder andere projektspezifische Nachweise müssen ausdrücklich abgeschlossen sein, bevor eine Freigabe behauptet wird.
